# Guide 15: Continuous integration (CI)

Step T-003. Every push and pull request runs the checks that need no GPU and no lab on GitHub's Linux machines. A red
result means do not merge. The lab tests (`tests/lab/`) stay manual: they need the GPUs.

Results: the **Actions** tab of the repository, or the badge at the top of the README.

## What runs

The workflow is `.github/workflows/ci.yml`. Its four jobs run side by side, in about two minutes.

| Job | What it checks | How |
| --- | --- | --- |
| shellcheck, yamllint, unit tests | Shell scripts have no common mistakes; every YAML file is valid as written; the installer's logic; recording rules; dashboards; links | `tests/run.sh` |
| oif-amd-share (gofmt, vet, test) | The AMD GPU sharing plugin is formatted, passes `go vet` and its unit tests | Go in `GO_BUILD_IMAGE`, the same image the installer builds with |
| patches apply to pinned upstream source | Every Run:ai and KAI Scheduler patch still applies to the source it is pinned to | `tests/check-patches.sh` |
| secret scan (gitleaks, full history) | No password, key or token in any commit, ever | gitleaks with `.gitleaks.toml` |

What `tests/run.sh` covers:

- **shellcheck** on `oif`, the installer, the build scripts and every test script.
- **yamllint** on all manifests (`.yamllint`). Manifests are templates: a `${NAME}` placeholder must sit where YAML stays valid, for example `["${JOIN_CA_HASH}"]`, not `[${JOIN_CA_HASH}]`.
- **Python syntax** of the installer tools and the lab probes.
- **Unit tests** in `tests/unit/`, among them:
  - `test_rules.sh`: the `oif:*` recording rules with promtool (in CI a failed download is a failure, not a skip);
  - `test_dashboards.sh`: dashboards are valid JSON and read only `oif:*` series;
  - `test_links.sh`: Markdown links between files in the repository resolve;
  - `test_render.sh`: every manifest and Run:ai template renders with no placeholder left.

## Pinned tools

Same rule as the platform: every version is pinned in `versions.env`, every download checked against its checksum.

| Tool | Setting in versions.env |
| --- | --- |
| shellcheck | `SHELLCHECK_VERSION`, `SHELLCHECK_SHA256` |
| yamllint | `YAMLLINT_VERSION` |
| gitleaks | `GITLEAKS_VERSION`, `GITLEAKS_SHA256` |
| promtool | `PROMETHEUS_VERSION`, `PROMETHEUS_SHA256` |
| Go | `GO_BUILD_IMAGE` (by digest) |
| Run:ai and KAI source | `RUNAI_VERSION`, `RUNAI_SOURCE_SHA256`, `KAI_VERSION`, `KAI_SOURCE_SHA256` |

The GitHub actions are pinned by commit, with the version in a comment (`actions/checkout@<commit>  # v7.0.1`).

## Run the same checks on your machine

On Linux (Ubuntu), from the repository folder:

```bash
sudo apt-get install -y shellcheck python3-pip
pip install --user yamllint==1.38.0
tests/run.sh                 # everything except Go, patches and the secret scan
tests/run.sh unit            # unit tests only
tests/check-patches.sh       # downloads the pinned source once (about 1 minute), cached in tests/.cache
```

Without shellcheck or yamllint, `tests/run.sh` skips them and says so; CI always runs them.

`tests/check-patches.sh` prints one line per patch:

```text
== run-ai-3.0.20
   ok   0001-cluster-sync-count-amd-gpus-on-mixed-nodes.patch
   ok   0002-frontend-amd-logo-for-rocm-images.patch
   ok   0003-go-operator-fractions-unavailable-without-target-nodes.patch
   ok   0004-frontend-new-cluster-points-to-oif.patch
== kai-v0.18.3
   ok   0001-common-amd-gpu-node.patch

   ok   0003-binder-fractions-on-amd-gpu-nodes.patch

```

A patch that no longer applies names the file and line:

```text
   FAIL 0002-scheduler-fractions-on-amd-gpu-nodes.patch
        error: patch failed: pkg/scheduler/plugins/gpusharingnodevalidation/gpusharingnodevalidation.go:11
```

## When a job fails

| Job | Usual cause | Fix |
| --- | --- | --- |
| shellcheck | a new warning | fix the script; disable a rule only on its line, with the reason |
| yamllint | a placeholder that makes YAML invalid, or bad indentation | quote the placeholder |
| unit tests | a behaviour change | fix the code, or the test if the change was intended |
| patches | `RUNAI_VERSION` or `KAI_VERSION` bumped | rebase the patches on the new source, then update the checksum |
| secret scan | a real secret: remove it, rewrite history and **change the secret**; a fake value in a test | allow that exact value in `.gitleaks.toml`, never a whole file |

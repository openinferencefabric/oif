Dynamo vs plain engine on the Radeon Pro W7900

open inference fabric · oif bench, profile full · 3 repeat(s) · AIPerf 0.13.0

What this measures

The Dynamo image is built FROM the plain engine image, so the engine, PyTorch and ROCm are the same files. Both get the same engine arguments, the same AIPerf prompts (fixed seed) and exact output lengths (ignore_eos), one at a time on one GPU that starts each point below 60 °C (it may run much hotter during the point: up to 104 °C here). What differs is Dynamo's frontend, request plane and worker wrapper. A small negative number is the price of that layer; Dynamo's gains (KV-aware routing across workers, disaggregation, planner) need more than one GPU and are not part of this test.

Not in this run: sglang, dynamo-sglang (no image pinned yet; SGLang needs spike S-5 on gfx1100 first).
